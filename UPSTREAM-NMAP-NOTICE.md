# Upstream relationship

This repository is a GitHub fork of [`nmap/nmap`](https://github.com/nmap/nmap).
The Noxmap implementation in this branch is a clean-room Rust rewrite and does
not incorporate upstream Nmap source files, Lua scripts, service databases,
branding, or assets.

The Git history preserves the upstream parent commit so the fork relationship
is transparent. Historical upstream material remains governed by its own
license and notices. Noxmap-specific source is independently authored; see
the package metadata for its declared license.
